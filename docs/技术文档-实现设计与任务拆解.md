`computeBranchIndex` 骨架（严格按《关联算法规格》§2）：

```js
function computeBranchIndex(localPath, base = 'master', maxCommits = 500) {
  if (!fs.existsSync(localPath)) throw { code: 'GIT_PATH_MISSING' }
  if (!fs.existsSync(path.join(localPath, '.git'))) throw { code: 'GIT_NOT_REPO' }

  const refs = runGit(['for-each-ref', '--format=%(refname:short)', 'refs/remotes/origin', 'refs/heads'], { cwd: localPath })
  const baseRef = 'origin/' + base
  const branches = [], unregistered = []

  for (const raw of refs.split('\n').map(s => s.trim()).filter(Boolean)) {
    if (isEnvBranch(raw)) continue
    const name = raw.replace(/^origin\//, '')

    let mb
    try { mb = runGit(['merge-base', baseRef, raw], { cwd: localPath }).trim() } catch { continue }
    if (!mb) continue

    const commits = Number(runGit(['rev-list', '--count', '--first-parent', `${mb}..${raw}`], { cwd: localPath }))
    if (commits === 0) { branches.push({ name, ids: [], commits: 0, merged: true, skipped: false }); continue }

    if (commits > maxCommits) { branches.push({ name, ids: [], commits, merged: false, skipped: true }); continue }

    const subjects = runGit(['log', '--first-parent', '--format=%s', `${mb}..${raw}`], { cwd: localPath })
    const ids = extractReqIds(subjects)
    const lastDate = runGit(['log', '-1', '--format=%ad', '--date=short', raw], { cwd: localPath }).trim()
    branches.push({ name, ids, commits, lastDate, merged: false, skipped: false })
    if (ids.length === 0) unregistered.push({ name, commits, lastDate })
  }
  return { branches, unregistered }
}
```

> 注释纪律（用户明确要求）：注释只解释**为什么**——例如「必须 `--first-parent`，否则会把分支 merge 进来的兄弟分支算成自己的工作量（实测踩过）」；**不要**写 `// 遍历分支` 这类逐行翻译式注释，也不要顺手为既有代码补解释性注释块。

## 6. 任务拆解

> 每项都写明**产出**与**验收点**；M1/M2/M2.5 **不依赖任何授权**，可立即开工。

### M0 · 基线与骨架（0.5d）

| 项 | 内容 |
|---|---|
| 产出 | ① 定稿并单独提交 `todo-release.js` 的 5.5 待决改动；② `server.js` 加 `json/fail/cacheGet/cacheSet/runGit/runMeegle` 基础设施与路由分发表；③ `todo_integration_config` 读写 |
| 验收 | 现有页面功能零回归；`/api/git-user`、`/api/branches` 响应结构与改造前逐字节一致 |

### M1 · 分支直读（0.5d）

| 项 | 内容 |
|---|---|
| 产出 | `GET /api/git/branches` 双通道 + 缓存 + 超时 + 环境分支过滤（补 `mdm*`/`*_old`/`*_copy`） |

### M2.5 · 未登记分支（0.5d）
